# Requirements Specification

- /summarize <url> fetches a URL, checks for existing summary, summarizes it, and saves as a PARA doc
- Steps: (1) find_existing_summary(url) for dedup, (2) if exists, return existing doc path, (3) if not, fetch_url(url), (4) LLM summarizes the content, (5) create_para_doc with summary, source URL in frontmatter, (6) auto-link runs automatically
- Default area: Resources. Override if user specifies.
- Tags: reuse existing via list_para_tags
- Content structure: ## Source (original title + URL), ## Summary (2-5 paragraphs), ## Key Points (bullets), ## Relevance

# Design Principles

- Dedup is strict — if a doc with the same source URL exists, don't re-summarize
- Fetch via fetch_url tool (handles PDF via pdftotext, HTML via Obscura/HTTP)
- Summary content is generated by the agent (the command outputs the URL for processing, agent summarizes)
- Simpler approach: /summarize runs the fetch, shows content to user, then agent summarizes and creates doc
- Or: command does the full pipeline, using tools for fetch and create, and the agent's response includes the summary
