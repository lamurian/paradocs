# Docs — Documentation

| Directory | Purpose                                |
|-----------|----------------------------------------|
| `ADR/`    | Architecture Decision Records          |
| `specs/`  | Detailed specifications by component   |
| `plans/`  | Implementation plans                   |

## Conventions

- ADRs follow the format from the `adr` skill (frontmatter, Context, Decision, Impact).
- One ADR per architectural decision, numbered sequentially.
- Specs cover a single component/extension in depth.
- Plans are time-boxed implementation steps.
- All `.md` files ≤100 lines.
